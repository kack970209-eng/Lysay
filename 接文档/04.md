## 完成內容

- 注音：不再用 `setMarkedText`（使用者看到的是显示在键盘顶部），改为 `showComposition` 把组字当普通文字写进输入框，每次只删改有差异的部分；用 `documentContextBeforeInput` 检查光标没被移走才删除
- AI 语音
  - 说话时每秒用 Qwen3-ASR 重新识别当前句子（`maybeLiveDecode`），说话框显示 Qwen 的结果，不再被 Paraformer 覆盖，中英文不会来回跳
  - 专有名词（`AppSettings.hotwords`，默认 Lysay）：传给 Qwen3-ASR 的 per-stream `hotwords` 选项、写进 AI 整理提示词、`normalizeHotwords` 把 LYSAY/lysay/Ly say 统一成设定写法
  - AI 整理提示词加“英文单词、品牌名保持英文原样，不翻译”
  - App 首页新增“专有名词”编辑页
- 粘贴板（`Shared/ClipStore.swift` 重写为 `ClipLibrary`：folders / items / history，删除用标记，按 updatedAt 合并）
  - 键盘开着时每 2 秒检查 `UIPasteboard.changeCount`，有新复制内容就记进剪贴板记录（最多 100 条，存本地 + 共享钥匙串，并经本机连接交给 App）
  - 键盘粘贴板面板：剪贴板 / 收藏 两个分页，收藏可进入文件夹；点一下输入；长按记录可删除
  - App 粘贴板页：剪贴板记录（点复制、左滑删除、长按收进文件夹、清空）+ 收藏文件夹（新建、重命名、删除、排序，文件夹内新增/编辑/删除/排序）
  - 旧版平铺的粘贴板内容自动搬进“常用”文件夹
- Cloudflare 后端（`server/`，已部署 https://lysay-api.kack970209.workers.dev ）
  - D1 数据库 `lysay`（id cb271179-cd75-4c12-8c48-043ceaaa9084，APAC），表：users、subscriptions、subscription_events、plans、clip_folders、clip_items、clip_history；套餐预设 monthly 150 TWD/30 天、yearly 550 TWD/365 天
  - API：`POST /v1/auth/apple`、`POST /v1/auth/google`（用 Apple/Google JWKS 验证身份令牌）、`GET /v1/me`、`POST /v1/usage`、`GET /v1/plans`、`POST /v1/sync`、`DELETE /v1/account`
  - 管理后台 `/admin`：统计、用户列表（搜索、登录方式、注册/最后登录、AI 已用时长、套餐“无/名称+到期日”、状态），可升级/续期套餐、取消套餐、停用/启用、重置额度、删除；套餐名称/价格/币别/天数可改
  - 机密：`SESSION_SECRET`、`ADMIN_PASSWORD` 已用 `wrangler secret put` 设置；后台密码存在本机 `server/.admin-password.txt`（已 gitignore，不提交）
  - 已用 curl 验证：/health、/v1/plans、后台登录与 stats/users、用户接口拒绝后台令牌
- App 账号（`Lysay/AccountManager.swift`、`Lysay/AccountView.swift`）
  - Sign in with Apple（`SignInWithAppleButton`）；Google 用 `ASWebAuthenticationSession` + PKCE（iOS 客户端，不需 SDK），客户端 ID 来自 Info.plist `LysayGoogleClientID`（CI 读 GitHub 仓库变量 `GOOGLE_IOS_CLIENT_ID`）

  - 首页新增“账号”区块（登录按钮 / 名字 + 方案摘要）、账号详情页（额度、到期、同步、退出、删除账号）、升级 Pro 页（显示后台套餐价格、复制用户 ID 给客服开通）
